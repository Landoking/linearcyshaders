Glow World Effect — 26.2 Pack Builder

Builds a resource pack for Minecraft 26.2 (pack format 88). Stack shader layers; each one switches on when a glowing entity of its color is on screen.
How it works: the pack replaces post_effect/entity_outline.json, the post effect the game runs while a glowing entity is on screen. Every layer is a full-screen shader pass. It reads the screen, the glow mask (which holds each entity's glow color) and, for depth effects, the depth buffer.
Glow colors: an entity glows in its team color, and white without a team. Give a layer a trigger color and it only runs while an entity glowing in that color is in view. Display entities can glow in any color with glow_color_override.
Install: put the zip in .minecraft/resourcepacks, enable it, press F3+T after any change. If the game reports an error loading entity_outline, send the log line.







FOV, render distance and cloud distance (Video Settings) only matter for depth effects: the shader needs them to rebuild 3D positions. Turn off FOV Effects (Accessibility) or sprinting will skew them a little. "Other entities" are glowing entities that no layer triggers on.
Layers run top to bottom, and each one sees the result of the layers above it. Untick a layer to leave it out of the pack.




Custom GLSL (advanced)
Runs at the end of this layer. You can use c (color), uv, texCoord, T (seconds), px (one pixel), m (trigger mask), amt (effect strength) and S(uv) (reads the screen). Errors show under the preview.
Every layer is shown as if its glow color is on screen, and the figure stands in for the glowing entity. Depth effects (AO, reflections, fog, distance pixelation) only show in game.
Import accepts settings files from this version or the older single-effect builder, packs made by either one (.zip), or an old world_effect.fsh. Your work is also kept in this browser between visits.
